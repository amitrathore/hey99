# Hey99

A recruiting preview for the third Community.Markets launch, focused on Manteca, Lathrop, Ripon, Salida and Escalon. The visual direction follows the Hey108 and HeyLaguna family while giving Highway 99 its own route identity.

The site is static HTML and CSS. Open `index.html` directly or serve the directory with `python3 -m http.server 8000`. There is no build or account backend. The primary call to action uses the existing [Community.Markets launch brief](https://community.markets/start), and all reward details point to its shared [earnings page](https://community.markets/economics/).

## GitHub Pages

Push the repository to GitHub, then in **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`. The site uses relative asset paths, so it works at either a project URL such as `https://<account>.github.io/hey99/` or a custom domain. Once the final URL is known, change the `og:image` meta tag in `index.html` to the absolute URL of `assets/og-card.png` for reliable social previews.

## Launch status

This is a preview. Hey99 offers, checkout and payouts are not active.
